# Everyday German sentences that are not commands (M6c).
#
# The negative corpus for *filler skipping*. `de-frequent.txt` is single words and answers a
# different question — whether a word can reach a keyword phonetically. This one is sentences,
# because skipping is a sentence-level rule: it lets a template match an utterance with extra
# words in it, and the risk it creates is that an ordinary remark, said in a kitchen with the
# wake word open, now lands inside a template that was anchored against exactly that.
#
# Every line is a sentence somebody says in a flat, dense in the particles the list skips —
# "doch", "mal", "eben", "denn", "jetzt", "eigentlich", "bitte", "das", "die", "ist". None of
# them may match any template with skipping on. A line that starts matching is a word that has
# to come off `Fillers.DE`, or a template that was never as anchored as it looked.
#
# The last block is a shape of its own: a sentence made of nothing but filler words and one
# command word ("es ist jetzt aus", "jetzt ist auch mal pause"). Those are remarks about the
# world, not instructions, and they are why nothing is skipped in *front* of a one-word template
# — a bare `aus` with leading skipping takes every one of them.
#
# "das war es dann" is deliberately **not** in here, although it has the same shape: it reaches
# `conversation.dismiss` through "das wars", and "that was it, then" really is a person ending
# the conversation. The line between the two groups is meaning, not shape.
#
# Several are deliberately one word away from a real command: "komm wir machen dann einfach weiter"
# against bare `weiter`, "hast du die zeit vergessen" against `was ist die zeit`, "weißt du eigentlich
# noch wie spät wir gestern wach waren" against `wie spät`. Those are the lines worth keeping when this file
# is edited.
#
# Lines starting with '#' are comments.
